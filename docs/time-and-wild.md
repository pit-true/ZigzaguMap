# 時間帯と野生ポケモン

### 時間帯ビューア（#432〜#434）

表示 > 時間帯 か、ツール欄の並べ替えのコンボの右のコンボで、マップを実機の昼夜の色（CFRU の DNS）で見られます。プロジェクトフォルダ（CFRU のフォルダ）を開いているときだけ使えます。ROM だけで開いているときは、コンボを使えなくし、説明に「CFRU-JP のフォルダ（プロジェクトのフォルダ）を開くと使えます」と出します（#543）。

- 区分は朝・昼・夕・夜の 4 つです。Chronos の深夜は、夜と同じに扱います（区分を出しません）。
- 起動したとき・ROM を開き直したときは、いつも昼です（覚えません）。昼は色を変えないので、絵は今までと同じです。
- 色はプロジェクトのソースから読みます: `src/config.h`（`TIME_ENABLED` と区分の範囲 `TIME_*_START`）、`include/new/dns_data.h`（10 分ごとの色の表 `gDNSNightFadingByTime`、色を変えるパレット `OW_BG_PAL_n`、夜だけ光るタイル `gSpecificTilesetFades`）、`include/new/dns.h`（Chronos の朝の「青を半分」の係数 `DNS_COEFF_HALVE_CHANNELS`）、`src/chronos_time.c`（Chronos の区分ごとの時刻）。読めないときは、ファイルと行と理由をステータスバーに出し、昼のままにします。
- ソースは、プロジェクトのフォルダの直下か、その中の `cfru` から探します（#543。`src/config.h` がある方。Chronos のルートを開いていても `Chronos\cfru` のソースを読みます）。どちらにも無ければ、探した場所をステータスバーに出します。連れ歩き・NPC の視界・会話の枠・感情アイコン・DPE の場所も、同じ場所から読みます。
- 区分ごとに、代表の時刻 1 つの色を出します。
  - Chronos: ゲームと同じ時刻（`sTimeOfDayHours`）。朝 6:00・昼 12:00・夕 18:00・夜 21:00。
  - ND: 実機の時計で動き、区分の中でも 10 分ごとに色が変わります。代表の時刻は Chronos と同じ朝 6:00・昼 12:00・夕 18:00・夜 21:00 にしました（区分の範囲は朝 4〜7 時・昼 8〜16 時・夕 17〜19 時・夜 20〜3 時）。
- 色の計算は `src/dns.c` と同じです。色の成分（0〜31）ごとに `c + (((混ぜる色 − c) × 係数) >> 4)`。真っ黒の色は変えません。変えるのはパレット 0〜12 のうち `OW_BG_PAL_n` が TRUE の本です。夜は、光るタイルの色を決まった色に置き換えます。
- マップの種類（場所の設定の「マップの種類」）が 0・地下・屋内・秘密基地のマップは、実機と同じく色を変えず、ステータスバーにそう出します。
- 色を変えるのは、マップの表示、隣のマップの帯、ダイブ先の重ね表示です。ブロックパレットとブロックエディタは、色を編集する所なので元の色のままです。
- 上のレイヤーを透かす判定は、色を変える前の色で比べます（色を変えると別の色が同じ色になることがあり、透ける画素が変わらないようにするため）。
- 色の表と計算の部品は、初めて昼以外にしたときに読み込みます。起動の時間とメモリは変わりません。

自動操作の命令は `view.timeOfDay`（docs/automation.md）。スクリプトの再生で Chronos の `settimeofday` を再現するときも、この命令（`settimeofday` の値を渡す）を使います。

### 時間帯別の野生（#436）

プロジェクトを開くと、野生ポケモンタブに朝・昼・夕・夜のタブが出ます。表の無い時間帯では、実機が昼の表を使うことを案内します。「昼の表をコピーして作る」か「空の表を作る…」で表を作れます。朝・夕・夜の表は消せて、作成・複製・削除はいずれも1回の「元に戻す」で戻せます。Chronos の深夜も夜の表を使います。

出力先は既存の `maps/BB/MM.json` の `Wild[].Time`（0 朝・1 昼・2 夕・3 夜）です。`python tests/realcopy/run.py --wildtime --reuse` で、ND・Chronos のコピーへの出力、ビルド、開き直しを確認できます。

野生ポケモンの検索は全時間帯を調べ、結果に時間帯を表示します。時間帯の欄で絞り、行をダブルクリックすると該当するマップと時間帯を開きます。出現率のグラフの題にも、今見ている時間帯を表示します（#437）。

### DPE の追加種族（#439）

プロジェクトで野生タブやトレーナー編集を初めて開くと、DPE の `include/species.h` と `strings/Pokemon_Name_Table.string` から種族番号と名前を読みます。ND は隣の `NeoDark-DPE-main`、Chronos は隣の `dpe` を探します。場所を変える場合は、CFRU の `zigzagumap.json` の最上位に `"dpeDirectory": "../自分のDPE"` を指定します。読み込めない場合はROMの名前表を使います。

野生の種族のコンボ、全マップ検索、トレーナーの手持ちの名前に同じ表を使います。追加種族も番号で出力し、開き直すと同じ番号と名前になります。ND の970件、Chronos の1573件（最後は0x624）を確認できます。`python tests/realcopy/run.py --species --reuse` が表示とJSON往復のテストです。

時間帯の色は人物にも使います（#435）。人物の画像情報のOBJパレット番号と `OW_SPRITE_PAL_n` を使い、黒と透明はそのままにします。屋内などの対象外のマップは、人物も背景も色を変えません。マップ画像の書き出しのウィンドウでは時間帯を選べます。最初は表示中の時間帯です。PNG・BMP・つなぎ合わせ・GIFに同じ指定を使い、表示中の時間帯は変えません。従来の画像保存は表示中の色のままです。
