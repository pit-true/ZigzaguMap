# ZigzaguMap

ファイアレッド日本語版（BPRJ）向けの、Windows用マップエディタです。マップ、イベント、タイルセット、野生ポケモン、スクリプトを編集し、CFRU-JPのプロジェクトへ書き出します。

ベースROMは読み取り専用です。変更は `maps/` のJSONやプロジェクトのソースへ出力し、プロジェクト側のビルドでROMに反映します。

## 使い始める

WindowsとWebView2が必要です。配布物は `zigzagumap.exe` 1つで、インストールは不要です。ROMは同梱していません。

1. `zigzagumap.exe` を起動し、ファイル > CFRU-JP のフォルダを開く（Ctrl+O）でCFRU-JPのフォルダを選びます。フォルダの中のベースROM（`BPRJ0.gba`）も自動で読み込みます。
2. ROMだけで使うときは、ファイル > ROMを開く（Ctrl+Shift+O）でBPRJのROMを選びます。
3. 左の一覧でマップをダブルクリックし、各タブで編集します。
4. ファイル > 出力（Ctrl+S）で変更を書き出します。ROMだけで開いた場合は、出力先のフォルダを選びます。

ROMやプロジェクトフォルダのドラッグ＆ドロップでも開けます。操作の詳細は[操作ガイド](docs/guide.md)を参照してください。

## 主な機能

- マップと移動許可の描画、スタンプ、オートペン、隣接マップと接続の編集
- 人物・ワープ・看板などのイベント、トレーナー、マップスクリプトの編集
- タイル・ブロック・パレットの編集、トリプルレイヤー、PNGからの取り込み
- 野生ポケモンの編集と全マップ検索、時間帯別の表、時間帯の色の表示
- 内蔵スクリプトエディタ、ラベルの参照・変更、プロジェクトのビルド
- スクリプトの再生とタイムライン、人物の移動・タイルアニメ・連れ歩きの確認
- ワールドマップの編集、マップ画像・つなぎ合わせ画像・GIFの書き出し

再生や時間帯の表示は実機と同じ動きを目指した確認用で、実機と違う所は各文書に書いています（[スクリプト編集と再生](docs/script-editor.md)）。

## ショートカット

| 操作 | キー |
|---|---|
| CFRU-JP のフォルダを開く | Ctrl+O |
| ROMを開く | Ctrl+Shift+O |
| 出力 | Ctrl+S |
| 元に戻す／やり直す | Ctrl+Z／Ctrl+Y |
| マップを指定して開く | Ctrl+M |
| グリッドの表示 | Ctrl+G |
| ブロックエディタ | Ctrl+B |

一覧は[操作ガイドのショートカット](docs/guide.md#ショートカット)にあります。アプリのヘルプ > ショートカット一覧では、変更したキーも確認できます。

## 設定

設定メニューから、表示・操作・ショートカットを変更できます。個人設定は `%APPDATA%\io.github.pit-true.zigzagumap\settings.json` に保存します。プロジェクトの設定と起動引数は[操作ガイド](docs/guide.md#設定)を参照してください。

## 開発

Node.js 22以降、pnpm、Rust 1.96以降と、WindowsのC++ビルド環境を使います。

```sh
pnpm install
pnpm lint
pnpm test
scripts\build.cmd
```

詳しい手順は[開発ガイド](docs/development.md)を参照してください。
